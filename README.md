
# 🏏 Digital Cricket Scouting System

### Machine Learning-Based Cricket Player Analysis and Scouting

## 📌 Project Overview

The Digital Cricket Scouting System is a web-based application that uses Machine Learning and Data Analytics to evaluate cricket players based on their historical performance.

The system helps identify talented players, analyze player statistics, and support data-driven decision-making in cricket scouting and franchise auctions.

## 🎯 Problem Statement

Traditional cricket scouting often depends on manual analysis, reputation, and subjective judgment.

This creates challenges such as:
- Difficulty identifying emerging talent.
- Time-consuming player performance analysis.
- Limited data-driven decision support.
- Challenges comparing players across different roles.

This project aims to make cricket scouting more systematic and efficient through statistical analysis and machine learning.

## 🚀 Key Features

- 🏏 **Player Performance Analysis** – Analyze batting and bowling statistics.
- 📊 **Data Visualization** – Explore player performance insights.
- 🤖 **Machine Learning Predictions** – Evaluate players using classification models.
- 🔍 **Role-Based Scouting** – Analyze batters, bowlers, and all-rounders.
- 🌟 **Emerging Talent Evaluation** – Assess prospective players using performance statistics.
- 🏆 **Auction Decision Support** – Assist in shortlisting players for franchise teams.
- 🌐 **Web Application** – Interactive frontend connected to backend APIs.

The project evaluates multiple classification algorithms:

1. **Naive Bayes**
2. **Decision Tree**
3. **Random Forest**

According to the original project documentation, Random Forest was selected for the application after comparing the models.

## ⚙️ How It Works

1. Historical cricket performance data is used for player evaluation.
2. Data preprocessing prepares relevant player statistics.
3. Machine learning models analyze performance indicators.
4. Flask APIs connect backend functionality to the frontend.
5. The React interface displays scouting information.
6. Users can evaluate players to support cricket recruitment decisions.
